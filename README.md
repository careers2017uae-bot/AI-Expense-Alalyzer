# AI-Expense-Alalyzer
AI Expense Analyzer prototype. This version will: ✅ Let the user enter expenses (date, amount, description, category) ✅ Store them in a local CSV (for simplicity) ✅ Use an LLM (OpenAI API) to analyze and categorize expenses ✅ Display charts (Bar, Pie, Line) using Plotly ✅ Run fully in Streamlit, so you can deploy instantly (e.g., Streamlit Cloud)
